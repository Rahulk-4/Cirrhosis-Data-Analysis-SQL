# 🩺 Cirrhosis Data Analysis Using SQL

## 📌 Project Overview
This project uses SQL to explore cirrhosis patient data, including demographics, clinical measurements, treatment information, disease stages, and patient outcomes.

## 🎯 Objectives
- Analyze patient demographics and gender distribution.
- Calculate average and maximum clinical measurements.
- Explore patient data by disease stage and treatment.
- Examine clinical indicators and patient outcomes.
- Practice filtering, grouping, and sorting healthcare data.

## 🛠️ Tools & Technologies
- **SQL**
- **MySQL-compatible queries**
- **Aggregate Functions**
- **GROUP BY and ORDER BY**
- **WHERE Conditions**
- **LIKE Operator**

## 📂 Project File
- `Cirrhosis_sql.sql` — SQL queries for exploring and summarizing cirrhosis patient data.

## 📚 Key SQL Concepts
SELECT, WHERE, GROUP BY, ORDER BY, COUNT, AVG, MAX, MIN, and LIKE.

## ✅ Conclusion
This project demonstrates SQL querying and data analysis techniques applied to cirrhosis patient data, helping summarize clinical measurements and explore patterns across patient groups.
